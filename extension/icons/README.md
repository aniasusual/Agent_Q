# Agent Q Icons

## Temporary Placeholder Icons

For Milestone 1, we're using simple placeholder icons. To create proper icons:

### Option 1: Use the HTML generator
1. Open `generate-icons.html` in your browser
2. Right-click each canvas and "Save image as..."
3. Save as:
   - icon16.png
   - icon48.png
   - icon128.png

### Option 2: Use an online tool
1. Visit: https://www.favicon-generator.org/
2. Upload a 512x512 image with your desired icon design
3. Download the generated icons
4. Rename them to icon16.png, icon48.png, icon128.png

### Option 3: Use existing emoji as icon (Quick Fix)
For now, you can use any 3 PNG files (16x16, 48x48, 128x128) as placeholders.

The extension will work even with missing icons (Chrome will show a default icon).

### Recommended Icon Design
- Colors: #4f46e5 (primary blue/indigo)
- Symbol: Robot emoji 🤖 or "Q" letter
- Style: Modern, clean, minimal
